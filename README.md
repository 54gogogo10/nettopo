# NetTopo · 网络拓扑设计器

一个**纯本地运行**（零安装、零后端）的网络拓扑可视化与编辑工具：

- **导入** CSV / TXT / Excel 连线关系表（自动识别 UTF-8 / GBK 编码、中英文表头）
- **自动生成**拓扑图（力导向布局，节点矩形碰撞分离，**绝不互相遮挡**），连线上**标注接口名与 IP**
- **手动修改**：拖拽、增删设备/连线、双击编辑、撤销重做、明暗主题
- **自定义设备类型**：可上传设备图片，拓扑中以图片显示（本机保存）
- **保存回表格**：把修改后的拓扑导出为 CSV / Excel 连线关系表
- **导出 PDF**：矢量渲染为高清图片嵌入 PDF，任何阅读器显示一致，适合交付/打印
- **导出 Visio**：生成 `.vsdx`（Visio 2013+ 原生格式），可在 Visio 中直接打开继续编辑

## 使用

直接双击打开 `index.html`（Chrome / Edge 等现代浏览器），或部署到任意静态服务器。

1. 点「导入表格」选择连线关系表、点「示例」体验内置数据，或点「新建空白画布」直接手动画
2. 自动布局后即可拖拽调整；双击设备/连线编辑接口与 IP
3. 「导出CSV / 导出Excel」保存连线表，「导出Visio」生成 Visio 文件

## 表格格式

| 表头（中）        | 表头（英）          | 必填 |
| ----------------- | ------------------- | ---- |
| 源设备 / 设备A / 设备1 | source / device_a   | ✅   |
| 源接口 / 接口A    | source_interface    |      |
| 源IP / IP地址A    | source_ip           |      |
| 目标设备 / 设备B / 设备2 | target / device_b   | ✅   |
| 目标接口 / 接口B  | target_interface    |      |
| 目标IP / IP地址B  | target_ip           |      |
| 带宽 / 备注       | bandwidth / note    |      |

无表头时按「设备A, 设备B, 接口A, IP A, 接口B, IP B」顺序识别。
设备类型（路由器/交换机/防火墙/服务器/终端/云）根据设备名自动推断；「类型」按钮可添加自定义类型并上传图片。

## 操作

| 操作               | 方式                              |
| ------------------ | --------------------------------- |
| 平移               | 拖拽空白处 / 中键                 |
| 缩放               | 滚轮（以光标为中心）              |
| 选中               | 单击设备或连线                    |
| 定位               | 面板/右键点击「定位」，金色脉冲圈标记目标 |
| 编辑               | 双击设备/连线（名称过长自动加宽节点） |
| 删除               | 选中后 Delete，或右键菜单         |
| 添加设备/连线      | 工具栏按钮，或右键空白处          |
| 设备类型管理       | 工具栏「类型」：自定义类型 + 图片上传 |
| 撤销 / 重做        | Ctrl+Z / Ctrl+Y                   |
| 自动布局 / 适应视图 | L / F                             |

## 项目结构

```
nettopo/
├── index.html         # 应用入口（双击打开）
├── css/style.css      # 样式（明暗双主题）
├── js/
│   ├── util.js        # 工具、CSV、几何、图标、配色、自定义类型注册表
│   ├── model.js       # 表头映射、表格⇄图转换
│   ├── layout.js      # 力导向布局 + 矩形碰撞分离（零遮挡）
│   ├── render.js      # SVG 渲染、视口、交互、定位脉冲
│   ├── visio.js       # VDX 导出（2003 格式，备用）
│   ├── vsdx.js        # VSDX 导出（2012 原生格式 + 内置 ZIP 写入器）
│   ├── pdf.js         # PDF 导出（SVG 渲染 + 手写 PDF 生成器）
│   └── app.js         # 主逻辑（UI、撤销、面板、类型管理、导入导出）
├── lib/xlsx.full.min.js  # SheetJS（离线 Excel 解析）
└── test/              # 单元测试、schema 校验、无头浏览器 e2e
```

## 开发测试

```bash
node test/run-tests.js        # 153 项单元测试（含 VSDX 结构校验、标注防碰撞、多行文字、管理地址回环）
cd test && npm i && node e2e.js   # 无头 Chrome 端到端（需本机 Chrome）
python test/validate_vdx.py test/sample_topology.vdx   # 单独校验 VDX（备用格式）
```

## 说明

- Excel 解析依赖本地内置 SheetJS，**完全离线可用**
- 浏览器无法覆盖写入磁盘原文件，「保存回表格」以导出文件形式提供
- 自定义类型与图片保存在浏览器 localStorage（本机）——清理浏览器数据会丢失
- 自定义类型图片暂不嵌入 Visio 导出（VDX 中以类型颜色标识）
