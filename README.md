# NetTopo · 网络拓扑设计与管理软件

一个**纯本地运行**（零安装、零后端）的网络拓扑可视化、编辑与运维工具：从连线关系表或设备邻居表一键生成拓扑，画布编辑与校验，导出 PDF / 图片 / Visio / Excel 交付；桌面版进一步提供 Web Shell、设备静默监控、配置备份与合规基线检查。全部数据仅保存在本机。

## 功能清单

### 画布与编辑

- **导入生成拓扑**：CSV / TXT / Excel 连线关系表（自动识别 UTF-8 / GBK 编码、中英文表头），自动布局（力导向 + 节点矩形碰撞分离，**绝不互相遮挡**），连线上标注接口名与 IP
- **手动编辑**：拖拽、增删设备/连线、双击编辑、撤销重做、明暗主题；Ctrl 点选 / Shift 框选多选，整体拖动、批量删除与批量编辑（设备与连线）
- **布局预设**：环形 / 分层（按类型）/ 三层架构 / 拓扑分层（最少交叉）/ 网格一键摆放；**直角（正交）布线**开关（画布与 PDF/PNG 导出同步，Visio 导出保持直线以便二次编辑）
- **画布快速搜索**：Ctrl+F 呼出悬浮搜索框，按设备名 / 类型 / 管理地址 / 备注 / 型号 / VLAN 与连线接口 / IP / 备注即输即搜，Enter / ↑ / ↓ 循环定位（选中 + 视图居中 + 金色脉冲）
- **区域分组容器**：画背景分组框（如核心区 / DMZ / 机房 A），设备拖入框内即归入该区域（按中心点几何判定），拖动区域整体移动，双击编辑名称 / 颜色 / 尺寸；随工程 / 图纸持久化，PDF / PNG / SVG / Visio 导出同步携带
- **多图纸**：一个工程多张拓扑页（按机房/楼层拆分），页签切换 / 重命名 / 删除；各页独立视图，后台监控覆盖全部页，旧版工程自动兼容为单页
- **自定义设备类型**：内置类型 + 自定义类型可上传图片（本机保存）；「编辑设备」还可指定设备级图标（11 种内置 + 上传）与**配置厂家**
- **设备模板库**：预置路由器/交换机/防火墙等模板，一键添加到画布中心
- **IP 子网计算器**：输入 IP 与掩码（支持 /26、点分掩码、反掩码，可留空默认 /24），即时算出网络地址 / 广播地址 / 可用范围 / 主机数并标注地址类型（/31 按 RFC 3021）；可从拓扑网段一键填充
- **网络故障模拟**：右键连线「标记链路故障（模拟断链）」，路径分析自动绕行

### 分析与校验

- **拓扑校验**：一键检查重复 IP、重复接口、孤立设备、环路、平行链路、跨网段等，报告内可点击定位到画布
- **路径分析**：选两台设备按带宽优选最宽路径并高亮（显示瓶颈带宽）与经过的接口
- **网段分析**：「布局 ▾ 网段分析…」把全部接口 IP / 三层 VLAN 接口 / 管理地址按 CIDR 网段汇总（管理地址无掩码信息按 /24 归组）：成员设备与链路、已用/可用地址与利用率、VLAN、来源构成；自动检测**网段重叠**（不同掩码规划冲突）、**网段/广播地址误用**与**超容量**，点击行定位并金色高亮该网段全部成员，支持导出 CSV
- **单点故障与影响分析**：「布局 ▾ 单点故障分析」一键找出单点设备（故障拆散网络）与无冗余关键链路（平行链路 / 聚合组成员互为冗余不计），点击条目定位并红色高亮受影响设备；右键设备/连线「故障影响分析…」模拟任一单点故障：查看失联区域（并列拆分时全部标红、无存续主网络），或存在冗余路径时高亮最短绕行路径；已标记故障的链路自动纳入计算
- **接口总表**：「编辑 ▾ 接口总表…」全部链路两端接口集中成一张可筛选表格（设备/接口/IP/掩码/VLAN/聚合组/二层/对端信息/备注），修改后「应用修改」一次性写入（单个撤销步骤），支持导出 CSV
- **链路聚合标记**：连线标记聚合组名（如 Eth-Trunk1 / Port-Channel1），同一对设备间同名聚合组的平行链路视为链路聚合——拓扑校验不再提示平行链路、路径分析按成员带宽之和计算容量（成员故障按剩余容量、全部故障则链路不可用）、标注第三行携带聚合名并同步 PDF/PNG/VSDX 导出；聚合组随 CSV/Excel 导入导出回环
- **对比工程**：「文件 ▾ 对比工程…」把另一份工程/表格与当前拓扑做差异对比（新增/删除/变更的设备与连线）

### 导入与交付

- **从邻居表导入（LLDP/CDP）**：「文件 ▾ 从邻居表导入…」粘贴 `display lldp neighbor`（华为/H3C，支持 brief 简表、键值块、「接口 has N neighbor(s)」段头）或 `show cdp neighbors`（思科表格 / detail 块）输出，自动识别格式解析出「本端接口 ⇄ 对端设备 ⇄ 对端接口」，预览确认后合并进拓扑——同名对端复用画布设备、新设备按名称推断类型自动创建、已有链路回填空缺接口、重复导入幂等；纯本机解析
- **保存回表格**：把修改后的拓扑导出为 CSV / Excel 连线关系表（含多管理口、VLAN、聚合组，可再导入）
- **导出 PDF / 图片**：PDF 矢量高清交付；PNG 高清图片 / SVG 矢量图；一键复制到剪贴板直接粘贴到聊天/文档
- **导出 Visio**：生成 `.vsdx`（Visio 2013+ 原生格式）可在 Visio 中继续编辑；自定义类型图片嵌入，连线为 2-D 直线（端点固定在设备边框，可手动调整）
- **导出资产清单 / IP 规划清单 / 设计报告**：资产清单（Excel）汇总设备名/类型/管理地址/型号/软件版本/监控状态/备份概况；IP 规划清单按设备列出全部管理口与接口 IP（同设备行合并、附对端信息与网段）；设计报告为自包含 HTML（设备/IP/子网/链路/带宽汇总）
- **生成设备配置**：按拓扑接口/IP 生成华为 / H3C / 思科 / 锐捷及自定义模板的配置片段（静态路由自动推导、接入端口 VLAN），可自由勾选只生成部分设备；每台设备可单独指定配置厂家；生成前自动**冲突检查**；支持下载 ZIP 按厂家分目录打包；模板掩码变量支持点分 `{mask}` / CIDR `{maskCidr}` / 反掩码 `{wildcard}` 三种
- **工程文件**：保存 / 打开 `.nettopo`（含位置、缩放、多图纸、自定义类型与监控配置），可选**口令加密**（PBKDF2-SHA256 + AES-GCM）

### 监控与运维（桌面版）

- **Web Shell**：右键设备 SSH/Telnet 连接管理口，独立窗口多标签管理，主界面不锁定；支持 SSH 密码/公钥认证、经 SSH 跳板机（堡垒机）连接（跳板/目标指纹独立确认）；底部**快捷按钮条**（SecureCRT Button Bar 风格，支持 \n 回车、\t 制表、\p 暂停）；顶栏「⇉ 群发」多标签命令广播，并可**对比**各标签输出、高亮差异行；会话内容自动写入本机审计日志，可在「监控日志…」浏览与全局搜索
- **设备管理 Web 页**：设备配置「管理Web页URL」后右键在独立窗口多标签打开；HTTPS 自签名证书弹安全告警（确认后可记住站点）；标准 Chrome UA、弹窗自动转新标签、页面缩放记忆
- **设备后台静默监控**：右键设备配置 SSH/Telnet 账号与命令，后台定时采集输出写入本地日志（按天归档），每个管理口可单独设置：**连接时执行命令**（每次连接仅执行一次）、**在线探测**（TCP/ICMP，离线弹通知）、**输出关键字告警**（多关键字全部命中显示、全部不再命中才解除，事件携带匹配行）、**配置自动备份**（复用监控连接 / 独立连接，可选自动合规）、**SNMP 识别**（sysDescr 自动回填软件版本）、**重启检测**（sysUpTime 骤减判定，记入事件时间线并弹通知）、**CPU/内存采集**（OID 可配置，华为/思科厂家预设一键填充）、**接口流量采集**（ifTable 采集每接口 UP/DOWN 与收发速率，64 位计数器优先）；支持**仅读取**与**仅探测**两种轻量模式
- **监控中心**：聚合全部监控状态、**近 7 天在线率**（10 分钟粒度，重启不丢）、「事件时间线 / 配置备份 / 接口流量 / 性能」四标签页（CPU/内存趋势线与开机时长；事件带设备徽标，点击设备名或管理地址筛选）；「监控日志…」支持全局跨文件搜索并点击定位到行
- **配置合规基线检查**：对备份库最新配置执行本地规则扫描（纯本机）。内置 **5 套基线模板**（等保通用 11 条 / 最小基线 / 华为 VRP / 思科 IOS / 接入层交换机）按需加载，也可把当前规则**另存为多套自定义模板**；规则按「时间同步 / 日志审计 / 认证与授权 / 服务与协议 / 路由与网关」五组分组，逐行正则（必须存在 / 禁止出现），禁止类自动排除 `undo`/`no` 关闭命令与 `stelnet` 误命中；违规定位到具体配置行，结果一键导出报告（Excel/CSV）；监控「自动合规」在每次备份后按当前规则集自动扫描
- **备份管理**：自动备份与「立即备份」集中存本机备份库，可浏览/恢复/删除/清空，按「保留最近 N 份」滚动清理
- **托盘常驻**：开启后关闭主窗口仅最小化到系统托盘，后台监控继续运行

## 使用

**推荐使用桌面版**（`dist/` 下的 `NetTopo-...-portable.exe`，免安装、零后端）：

- 支持全部功能，包括 **Web Shell（SSH/Telnet）独立多标签窗口**、**设备静默监控**、**配置合规检查**与**工程自动备份**
- 启动后左下角状态栏显示版本号（如 `v20260829i`）

也可直接用浏览器打开 `index.html`（Chrome / Edge）或部署到任意静态服务器——画布编辑、导入导出等核心功能均可用；**Web Shell、后台监控与合规检查为桌面版专属**（浏览器无本地网络能力）。

1. 「文件 ▾ 导入表格」选择连线关系表、「文件 ▾ 从邻居表导入」粘贴设备邻居表输出，或「新建空白画布」直接手动画
2. 自动布局后即可拖拽调整；双击设备/连线编辑接口与 IP
3. 「导出 ▾」选择 CSV / Excel / PDF / 图片 / Visio / 资产清单等交付；「保存工程」随时存档，下次「打开工程」继续编辑

### Linux（麒麟/服务器）运行

构建产物：`dist/linux/nettopo-<版本>-linux-x64.tar.gz`（本地用 `build/electron-builder-linux.yml` 交叉打包，`npmRebuild=false`，产物不入库）。

- **root / sudo 运行**：已内置自动兜底——主进程检测到 Linux 且 `getuid()===0` 时自动追加 `--no-sandbox`，无需手动传参即可启动。
- **普通用户启动报 SUID 沙箱错误**（`chrome-sandbox is not configured correctly`）：解包后执行
  `sudo chown root:root chrome-sandbox && sudo chmod 4755 chrome-sandbox` 修复；部分发行版禁用了用户命名空间时，可临时以 `./nettopo --no-sandbox` 启动。
- 注意：以 root 运行需 `--no-sandbox` 是 Chromium 的安全限制，此时进程级沙箱被旁路；建议权限允许时用普通用户 + 正确 setuid 的 chrome-sandbox 运行，以保留完整沙箱保护。普通用户的正常运行不受本兜底逻辑影响。

## 表格格式

| 表头（中）        | 表头（英）          | 必填 |
| ----------------- | ------------------- | ---- |
| 源设备 / 设备A / 设备1 | source / device_a   | ✅   |
| 源接口 / 接口A    | source_interface    |      |
| 源IP / IP地址A    | source_ip           |      |
| 目标设备 / 设备B / 设备2 | target / device_b   | ✅   |
| 目标接口 / 接口B  | target_interface    |      |
| 目标IP / IP地址B  | target_ip           |      |
| 带宽 / 备注       | bandwidth / note    |      |
| 管理地址          | mgmt / management   |      |
| 聚合组            | eth-trunk / lag / aggregate |  |

无表头时按「设备A, 设备B, 接口A, IP A, 接口B, IP B, 带宽, 备注」顺序识别；可选列「聚合组」（表头别名：链路聚合 / Eth-Trunk / Port-Channel / LAG）标记链路聚合组。

> 带宽统一为 **Mbps 数值**（如 `100`/`1000`/`10000`）；旧表格中的「百兆/千兆/万兆、10Gbps」等文字会自动换算。拓扑图上**不显示带宽文字**，连线按带宽着色（100M 灰 / 1G 蓝 / 10G 紫 / 40G 橙 / 100G 红），图例显示在面板与导出图中。
设备类型（路由器/交换机/防火墙/服务器/终端/云）根据设备名自动推断；「编辑 ▾ 类型管理」可添加自定义类型并上传图片。

## 项目结构

```
nettopo/
├── index.html         # 主窗口入口（浏览器/Electron 通用）
├── shell.html         # Web Shell 独立窗口（多标签终端）
├── webview.html       # 设备管理 Web 页窗口（多标签内嵌浏览器）
```

## 说明

- Excel 解析依赖本地内置 SheetJS，**完全离线可用**
- 浏览器无法覆盖写入磁盘原文件，「保存回表格」以导出文件形式提供
- 自定义类型与图片保存在浏览器 localStorage（本机）——清理浏览器数据会丢失，建议用「保存工程」备份
- 桌面版 Web Shell 支持 SSH（密码/keyboard-interactive）与 Telnet（RFC854 协商 + 窗口尺寸 NAWS）；SSH 主机密钥首次连接展示 SHA256 指纹并记忆，指纹变化时拒绝连接（内网实验环境默认信任首连）
- 后台监控日志（`userData/monitor-logs`）、配置备份（`userData/config-backups`）与监控配置（含密码）均保存在本机用户数据目录；密码经系统级加密（Windows DPAPI safeStorage）后落盘，监控指纹记录同样存于本机
- 版本号唯一来源是 `js/util.js` 的 `U.APP_VERSION`（如 `v20260829i`），界面标题/状态栏同步显示；`npm run build` 会自动升版本并重建产物；package.json 的语义版本仅为 Electron 打包用途
- 安全策略：三个页面均启用 CSP（script-src 仅 'self'，无 'unsafe-eval'——本地内置 SheetJS 与全部应用代码均不使用 eval，其余来源严格限定本地/data/blob）；所有本地文件/日志/备份路径走白名单式文件名清洗，杜绝路径穿越
