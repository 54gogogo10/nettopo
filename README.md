# NetTopo · 网络拓扑设计器

一个**纯本地运行**（零安装、零后端）的网络拓扑可视化与编辑工具：

- **导入** CSV / TXT / Excel 连线关系表（自动识别 UTF-8 / GBK 编码、中英文表头）
- **自动生成**拓扑图（力导向布局，节点矩形碰撞分离，**绝不互相遮挡**），连线上**标注接口名与 IP**
- **手动修改**：拖拽、增删设备/连线、双击编辑、撤销重做、明暗主题
- **自定义设备类型**：可上传设备图片，拓扑中以图片显示（本机保存）
- **保存回表格**：把修改后的拓扑导出为 CSV / Excel 连线关系表
- **工程文件**：保存 / 打开 `.nettopo` 工程（含位置、缩放、多图纸、自定义类型与监控配置），不再依赖浏览器缓存；可选**口令加密**（PBKDF2-SHA256 + AES-GCM，打开/对比加密工程时输入口令）
- **导出 PDF / 图片**：PDF 矢量高清交付；PNG 高清图片 / SVG 矢量图便于发群与文档
- **拓扑校验**：一键检查重复 IP、重复接口、孤立设备、环路、平行链路、跨网段等，并可定位到画布
- **多选 / 批量**：Ctrl 点选、Shift 框选，整体拖动、批量删除与批量编辑（设备与连线）
- **画布快速搜索**：Ctrl+F 呼出悬浮搜索框，按设备名 / 类型 / 管理地址 / 备注 / 型号 / VLAN 与连线接口 / IP / 备注即输即搜，Enter / ↑ / ↓ 循环定位（选中 + 视图居中 + 金色脉冲），点击结果直接跳转
- **区域分组容器**：「编辑 ▾ 添加区域…」或右键画布「在此添加区域」画背景分组框（如核心区 / DMZ / 机房 A），设备拖入框内即归入该区域（按中心点几何判定），拖动区域时框内设备与文本框整体移动，双击区域编辑名称 / 颜色 / 尺寸；随工程 / 图纸 / 自动备份持久化，PDF / PNG / SVG / Visio 导出同步携带（Visio 中为底层虚线矩形，可继续编辑）
- **IP 子网计算器**：「编辑 ▾ IP 子网计算器…」输入 IP 与掩码（支持 /26、点分掩码、反掩码三种格式，可留空默认 /24），即时算出网络地址 / 广播地址 / 可用范围 / 可用主机数 / 反掩码并标注当前地址类型（网络 / 广播 / 主机，/31 按 RFC 3021）；可从拓扑中出现的网段一键填充，结果一键复制
- **导出 Visio**：生成 `.vsdx`（Visio 2013+ 原生格式），可在 Visio 中直接打开继续编辑；自定义类型图片作为图片形状嵌入，**连线为 2-D 直线**（端点固定在设备边框上，拖动设备后线不自动跟随，可在 Visio 中手动调整）
- **复制到剪贴板**：一键把拓扑图复制成图片，直接粘贴到聊天/文档
- **布局预设**：环形布局、分层布局（按类型）、网格布局一键摆放；**直角（正交）布线**开关（画布与 PDF/PNG 导出同步，Visio/VSDX 导出保持直线以便二次编辑）
- **多图纸**：一个工程多张拓扑页（按机房/楼层拆分），顶部页签切换/重命名/删除；各页独立视图，后台监控覆盖全部页，旧版工程文件自动兼容为单页
- **路径分析**：选两台设备高亮最优路径（按带宽优选，显示瓶颈带宽）与经过的接口
- **设备模板库**：预置路由器/交换机/防火墙等模板，一键添加到画布中心
- **生成设备配置**：「导出 ▾ 生成设备配置…」按拓扑接口/IP 生成华为/思科等厂家配置片段（含静态路由自动推导、接入端口 VLAN），可**「选择设备」自由勾选只生成部分设备的配置**（搜索/全选/清空/反选），画布有选中设备时默认只生成选中设备；**每台设备可在「编辑设备」中单独指定配置厂家**（默认跟随生成时的全局选择），生成前自动做**冲突检查**（一端二层一端三层视为正常桥接场景，不再报错），支持**「下载 ZIP」**按厂家分目录打包；自定义模板掩码变量支持点分 / CIDR / 反掩码三种——{mask}（255.255.255.0）、{maskCidr}（/24）、{wildcard}（0.0.0.255）；「编辑设备」中还可为设备指定**自定义图标**（11 种内置图标 + 上传图片，画布按正方形显示）
- **Web Shell（桌面版）**：选中设备右键「Web Shell（SSH/Telnet）」连接管理口；在**独立窗口**以**多标签**方式管理多台设备，主界面不锁定可继续操作拓扑；支持 SSH **密码/公钥**认证与 Telnet；会话内容自动写入本机**审计日志**（`monitor-logs/WebShell-主机/` 按天归档，可在「监控日志…」中浏览与全局搜索）。每台设备可配置**多个管理口地址**（默认一个，编辑设备时点击「＋ 增加管理口」），Web Shell 连接时可下拉选择；Web Shell 底部带**快捷按钮条**（SecureCRT Button Bar 风格）：右键或点「＋」新建按钮，点击把预置命令发送到当前会话，支持 \n 回车、\t 制表、\p 暂停 1 秒，编辑/删除/排序，配置本机记忆；顶栏「⇉ 群发」开启**多标签命令广播**（SecureCRT Chat Window 模式）：勾选标签后一条命令同时下发到全部勾选会话，并可**「对比」汇总各标签输出、高亮差异行**；连接弹窗支持**经 SSH 跳板机（堡垒机）连接**（跳板/目标指纹各自独立确认）
- **设备管理 Web 页（桌面版）**：设备可配置「管理Web页URL」，右键设备「打开设备管理页面」在**独立窗口**以**多标签**方式打开多个设备的管理网页，主界面不锁定；HTTPS 自签名/无效证书会弹出**安全告警**，手动确认“继续访问”后加载，并可记住该站点（本次运行）；显示兼容性：使用标准 Chrome UA（去掉 Electron 标识）、抑制 alert/confirm/prompt 弹窗、window.open 弹窗自动转为新标签、页面缩放 A−/A+（Ctrl+-/Ctrl+=，记忆）
- **网络故障模拟**：右键连线「标记链路故障（模拟断链）」，路径分析自动绕行
- **备份管理（桌面版）**：自动备份与「立即备份」集中保存到本机备份库（用户数据目录），「备份管理」面板可浏览时间/大小、一键恢复、删除与清空，并按「保留最近 N 份」自动滚动清理（可在自动备份设置中调整）
- **配置合规基线检查（桌面版）**：「监控 ▾ 配置合规检查…」或配置备份中心「合规检查…」对备份库中各地址的**最新配置**执行本地规则扫描（默认：必须 NTP/AAA/默认路由，禁 Telnet 服务/SNMP v1v2c community；规则为逐行正则，可自定义、启用/停用、恢复默认），违规项**定位到具体配置行**，纯本机不上传；扫描结果可**一键导出报告**（Excel/CSV）；监控开启自动备份后可勾选**「自动合规」**——每次备份保存后自动扫描，违规写入事件时间线并弹通知
- **设备后台静默监控（桌面版）**：右键设备「设备监控（静默采集）…」配置 SSH/Telnet 账号与命令后，后台定时采集命令输出并写入本地日志（**按天归档**：`monitor-logs/设备名/日期/<设备名>_<管理口>.log`，同一天连接/重连只追加同一文件）。每个管理口可单独设置**连接时执行命令**（每行一条可多条，每次连接成功仅执行一次）、**在线探测**（TCP/ICMP，离线变红并弹通知）、**输出关键字告警**（多关键字同时命中全部显示，**全部不再命中才解除**，告警事件携带具体匹配行）与**配置自动备份**（命令可多条合并保存；连接方式可选**复用监控连接 / 独立连接**；首份备份显示「首次」而非「有变化」；可勾选**自动合规**——备份后按规则扫描，违规进事件时间线并弹通知）、**SNMP 识别**（v2c 读取 sysDescr/sysObjectID，零依赖实现，自动回填设备「软件版本」）与**接口流量采集**（SNMP v2c ifTable 零依赖 GETNEXT 遍历：按间隔采集接口状态与收发流量，64 位计数器优先 32 位兜底；监控中心「接口流量」页按设备查看每接口 UP/DOWN、出入速率、带宽利用率与近 120 次采样趋势线，接口 DOWN 记入事件时间线并弹通知）；**仅读取模式**同样支持探测 / 告警 / 备份，**仅探测模式**可不勾仅读取、不填命令、只勾选「在线探测」即只做连通性监测。「监控日志…」支持**全局跨文件搜索**（一次搜全部设备 / 日期 / 文件，点击结果定位到行）
- **监控中心（桌面版）**：工具栏「监控 ▾ 监控中心…」或右键设备进入，**聚合全部监控状态**（在线/离线/告警/备份统计）、**近 7 天在线率**（探测采样 10 分钟粒度，按天着色，重启不丢）、**事件时间线**（离线/恢复/告警/告警解除/备份变化/接口离线/接口恢复，事件带设备徽标与具体告警内容）与**配置备份一览**及**接口流量**——「事件时间线 / 配置备份 / 接口流量」以**标签页**切换，**点击设备名或管理地址可筛选时间线**，打开期间实时刷新
- **托盘常驻（桌面版）**：监控配置弹窗或「监控 ▾」菜单开启后，**关闭主窗口仅最小化到系统托盘**，后台监控继续运行，点托盘图标恢复主窗口

## 使用

**推荐使用桌面版**（`dist/` 下的 `NetTopo-...-portable.exe`，免安装、零后端）：

- 支持全部功能，包括 **Web Shell（SSH/Telnet）独立多标签窗口**、**工程自动备份与备份管理**
- 启动后左上角状态栏显示版本号（如 `v20260812m`）

也可直接用浏览器打开 `index.html`（Chrome / Edge）或部署到任意静态服务器——画布编辑、导入导出等核心功能均可用，**Web Shell 为桌面版专属**（浏览器无本地网络能力）。

1. 点「导入表格」选择连线关系表、点「示例」体验内置数据，或点「新建空白画布」直接手动画
2. 自动布局后即可拖拽调整；双击设备/连线编辑接口与 IP
3. 「导出CSV / 导出Excel / 导出PDF / 导出图片 / 导出Visio」交付；「保存工程」随时存档，下次「打开工程」继续编辑

### Linux（麒麟/服务器）运行

构建产物：`dist/linux/nettopo-<版本>-linux-x64.tar.gz`（本地用 `build/electron-builder-linux.yml` 交叉打包，`npmRebuild=false`，产物不入库）。

- **root / sudo 运行**：已内置自动兜底——主进程检测到 Linux 且 `getuid()===0` 时自动追加 `--no-sandbox`，无需手动传参即可启动。
- **普通用户启动报 SUID 沙箱错误**（`chrome-sandbox is not configured correctly`）：解包后执行
  `sudo chown root:root chrome-sandbox && sudo chmod 4755 chrome-sandbox` 修复；部分发行版禁用了用户命名空间时，可临时以 `./nettopo --no-sandbox` 启动。
- 注意：以 root 运行需 `--no-sandbox` 是 Chromium 的安全限制，此时进程级沙箱被旁路；建议权限允许时用普通用户 + 正确 setuid 的 chrome-sandbox 运行，以保留完整沙箱保护。普通用户的正常运行不受本兜底逻辑影响。

## 表格格式

| 表头（中）        | 表头（英）          | 必填 |
| ----------------- | ------------------- | ---- |
| 源设备 / 设备A / 设备1 | source / device_a   | ✅   |
| 源接口 / 接口A    | source_interface    |      |
| 源IP / IP地址A    | source_ip           |      |
| 目标设备 / 设备B / 设备2 | target / device_b   | ✅   |
| 目标接口 / 接口B  | target_interface    |      |
| 目标IP / IP地址B  | target_ip           |      |
| 带宽 / 备注       | bandwidth / note    |      |

无表头时按「设备A, 设备B, 接口A, IP A, 接口B, IP B」顺序识别。

> 带宽统一为 **Mbps 数值**（如 `100`/`1000`/`10000`）；旧表格中的「百兆/千兆/万兆、10Gbps」等文字会自动换算。拓扑图上**不显示带宽文字**，连线按带宽着色（100M 灰 / 1G 蓝 / 10G 紫 / 40G 橙 / 100G 红），图例显示在面板与导出图中。
设备类型（路由器/交换机/防火墙/服务器/终端/云）根据设备名自动推断；「编辑 ▾ 类型管理」可添加自定义类型并上传图片。

## 项目结构

```
nettopo/
├── index.html         # 主窗口入口（浏览器/Electron 通用）
├── shell.html         # Web Shell 独立窗口（多标签终端）
├── webview.html       # 设备管理 Web 页窗口（多标签内嵌浏览器）
├── electron-main.js   # Electron 主进程（窗口管理、Shell/Web IPC、事件队列）
├── preload.js         # 渲染层↔主进程安全桥（contextBridge）
├── css/style.css      # 主界面样式（明暗双主题）
├── css/shell.css      # Web Shell 窗口样式
├── js/
│   ├── util.js        # 工具、CSV、几何、图标、配色、类型注册表、数据清洗
│   ├── model.js       # 表头映射、表格⇄图转换、拓扑校验
│   ├── layout.js      # 力导向布局 + 矩形碰撞分离（零遮挡）
│   ├── render.js      # SVG 渲染、视口、交互、定位脉冲
│   ├── visio.js       # VDX 导出（2003 格式，备用）
│   ├── vsdx.js        # VSDX 导出（2012 原生格式 + 内置 ZIP 写入器）
│   ├── pdf.js         # PDF 导出（SVG 渲染 + 手写 PDF 生成器）
│   ├── shell.js       # SSH/Telnet 会话管理（主进程，纯 Node）
│   ├── backup-store.js # 工程备份库（本机备份目录、滚动保留、文件名校验，主进程）
│   ├── shell-ui.js    # Web Shell 窗口标签/终端逻辑
│   ├── webview-ui.js  # 设备管理页窗口标签/内嵌浏览器逻辑
│   └── app.js         # 主逻辑（UI、撤销、面板、类型管理、导入导出）
├── lib/               # xlsx（离线 Excel）、xterm（终端模拟器）
└── test/              # 单元测试、schema 校验、无头浏览器 e2e、Electron 冒烟
```

## 说明

- Excel 解析依赖本地内置 SheetJS，**完全离线可用**
- 浏览器无法覆盖写入磁盘原文件，「保存回表格」以导出文件形式提供

- 桌面版 Web Shell 支持 SSH（密码/keyboard-interactive）与 Telnet（RFC854 协商 + 窗口尺寸 NAWS），SSH 主机密钥以 SHA256 指纹展示（内网实验环境默认信任）
- 后台监控日志（`userData/monitor-logs`）、配置备份（`userData/config-backups`）与监控配置（含密码）均保存在本机用户数据目录，密码经系统级加密（Windows DPAPI safeStorage）后落盘，监控指纹记录同样存于本机
- 版本号统一由 `js/util.js` 的 `U.APP_VERSION` 维护，界面标题/状态栏/控制台同步显示；package.json 的 1.0.0 仅为 Electron 打包语义版本，发布版本以 U.APP_VERSION 为准。安全策略：三个页面均启用 CSP（script-src 仅 'self'，无 'unsafe-eval'——本地内置 SheetJS 与全部应用代码均不使用 eval，其余来源严格限定本地/data/blob）；SSH 主机密钥首次连接展示 SHA256 指纹并记忆，指纹变化时拒绝连接
